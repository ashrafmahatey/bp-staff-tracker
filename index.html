Firebase Setup Required
One-time setup — takes about 3 minutes
📋 Steps to set up cloud sync:
1. Go to console.firebase.google.com
2. Click "Create a project"
3. Name it: BP Wetlands Staff Tracker
4. Turn off Google Analytics → Create project
5. Click the </> web icon → Name it Staff Tracker → Register
6. Copy the firebaseConfig block shown
7. Go to Build → Realtime Database → Create Database
8. Choose Europe-West → Start in test mode
9. Paste your config to Claude and ask to add it to the app
⚠️ The app needs Firebase to work across devices. Paste your config in the Claude chat and I'll update the file for you.
